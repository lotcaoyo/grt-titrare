# GRT Titrare

Титры на румынском из русского видео. Тайм-коды берутся из речи.

---

## Запуск


Скопируйте папку на компьютер и запустите «GRT Titrare.bat».
Первый раз ставится Python внутрь самой папки — минуты две, нужен интернет.
Права администратора не нужны, в систему ничего не прописывается.



## Первый раз на новой машине


Откроется вкладка «Компоненты» → «Установить всё».
Качается около 4 ГБ, из них 3 ГБ — модель распознавания.

Последней пройдёт «Проверка готовности». Она скажет главное:
работает видеокарта или расчёт идёт на процессоре, и сколько
займёт фильм на 25 минут.

Драйвер NVIDIA приложение поставить не может — это единственное,
что делается вручную.



## Работа


1. Перетащите фильмы в окно. Можно сразу пачкой.
2. Ждите. Машина обработает всё подряд.
3. У готового фильма нажмите «Перевести».
   Кнопка «Скопировать» → вставьте в чат → ответ вставьте обратно
   → «Применить».
4. Файл .srt появится рядом с самим видео.

Ни в какие папки заходить не нужно.


## Ярлык на рабочем столе

Создаётся сам при первом запуске. Если удалили и захотели вернуть —
вкладка «Компоненты», строка «Ярлык на рабочем столе», кнопка «Установить».

Ярлык запускает приложение напрямую, без чёрного окна.


## Вкладка «Готово»

Все собранные титры в одном списке, свежие сверху. Каждый файл назван
по имени фильма.

Посмотреть      — прочитать титры прямо в окне
Открыть         — открыть файл в системе
Показать файл   — найти его в Проводнике
Сохранить копию — положить в нужное место под нужным именем

Записи сгруппированы по давности: сегодня, вчера, на этой неделе,
в этом месяце, раньше.

Крестик справа на карточке убирает один фильм из списка.
Кнопка «Очистить историю» — все сразу, с подтверждением.

Убирается только запись. Сам файл титров остаётся лежать рядом
со своим видео.

Поиск сверху фильтрует по названию фильма.

Кнопка «Собрать в папку» копирует всё, что сейчас в списке, в одну
выбранную папку. Если включён поиск, соберётся только отфильтрованное —
удобно, когда пачка фильмов должна уехать монтажёру вместе.



## Что ещё есть на карточке


Расшифровка    — русский текст, распознанный из фильма
Сверка RU / RO — русский и румынский построчно
Показать файл  — открыть проводник на готовом .srt
Повторить      — прогнать заново, если что-то пошло не так



## Термбаза — главное для качества


Файл termbase.yaml. Слева русское написание, справа румынское.
Заполните раздел people фамилиями из ваших фильмов, иначе имена
придётся править руками в каждом файле.

Общая термбаза на всю редакцию: положите файл на сетевую шару
и укажите путь в config.yaml → termbase → shared_path.



## Обновления


config.yaml → update → repo: "ваш-логин/grt-titrare"

Дальше приложение само проверяет GitHub при запуске. Если версия
в manifest.json репозитория выше — сверху появляется полоска
«Доступна версия …» и кнопка «Обновить». Обновление весит
десятки килобайт: заменяется только код, модель и библиотеки
остаются на месте.

Ваши config.yaml и termbase.yaml при обновлении не трогаются.



## Если что-то пошло не так


Кнопка «Подробно» на карточке фильма — журнал по этому файлу.
Вкладка «Компоненты», «Подробно» под строкой — лог установки.
Папка logs — журналы запуска.
